## Описание
Этот проект содержит автоматизированные тесты для API, связанного с курьерами и заказами в системе. Тесты проверяют правильность работы нескольких конечных точек API, включая регистрацию курьеров, авторизацию, создание заказов и получение списка заказов.

## Тестируемые API

1. **Создание курьера**  
   - Тестирование регистрации нового курьера.
   - Проверка, что нельзя создать двух одинаковых курьеров.
   - Проверка обязательных полей для создания курьера.
   - Проверка кода ответа и тела ответа при успешной и неуспешной регистрации.

2. **Авторизация курьера**  
   - Проверка успешной авторизации курьера.
   - Тестирование с неверными данными для логина или пароля.
   - Проверка обязательных полей для входа.
   - Проверка кода ошибки при отсутствии логина или пароля.

3. **Создание заказа**  
   - Проверка создания заказа с указанием одного цвета (BLACK или GREY).
   - Тестирование создания заказа с двумя цветами.
   - Тестирование создания заказа без указания цвета.
   - Проверка кода ответа и наличия поля `track` в ответе.

4. **Получение списка заказов**  
   - Проверка получения списка заказов.
   - Проверка, что в ответе всегда возвращается список заказов.

## Как запустить тесты

### Требования

1. Python 3.x
2. Установленные библиотеки:
   - `pytest`
   - `requests`
   - `allure-pytest`

## Структура проекта
- api_methods.py - Содержит методы для взаимодействия с API (регистрация курьера, авторизация, создание заказа и т. д.)
- data.py - Содержит данные для тестов, такие как тестовые данные курьеров и заказов.
- helpers.py - Содержит вспомогательные функции, например для генерации случайных строк.
- urls.py - Содержит URL-адреса для всех API конечных точек.
- conftest.py - Содержит фикстуры для создания и удаления курьеров перед и после тестов.
- test_create_courier.py - Тесты для создания курьера.
- test_login_courier.py - Тесты для авторизации курьера.
- test_create_order.py - Тесты для создания заказа.
- test_get_orders.py - Тесты для получения списка заказов.
- allure-results/ - Папка с результатами выполнения тестов в формате, подходящем для Allure.
